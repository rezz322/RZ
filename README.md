# Telegram-бот розкладу для групи РЗ-263 (ІІБРТ, Одеська політехніка)

Telegram-бот на **aiogram 3** та **httpx**, який автоматично моніторить оновлення розкладу на сайті факультету ІІБРТ (`https://op.edu.ua/studies/iibrt`), завантажує актуальний документ з Google Drive, парсить його та показує розклад для групи **РЗ-263** з урахуванням **парних та непарних тижнів** (чисельник / знаменник).

---

## 🎯 Можливості бота

1. **Автоматичний моніторинг оновлень:**
   - Періодично опитує Google Drive папку 1-го курсу ІІБРТ (`1Jlt45-PyFNJjfbNw1UVHWQ9GxzT5xizo`).
   - Якщо файл змінено на сервері — автоматично завантажує нову версію, парсить та розсилає сповіщення усім користувачам бота.
2. **Аналіз парних і непарних тижнів:**
   - **Непарний тиждень (чисельник):** тижні 1, 3, 5, 7, 9, 11, 13, 15.
   - **Парний тиждень (знаменник):** тижні 2, 4, 6, 8, 10, 12, 14.
   - Підтримка здвоєних пар (наприклад: *у непарний тиждень практика, у парний — лабораторна*).
   - Підтримка дисциплін із плаваючим початком (наприклад, `3-15 н/пар` — заняття тільки з 3-го тижня).
3. **Швидкі команди та кнопки:**
   - `📅 Сьогодні` — розклад на поточний день із точним визначенням поточного тижня.
   - `📅 Завтра` — розклад на наступний навчальний день (у п'ятницю/суботу показує розклад на понеділок).
   - `🗓 Непарний тиждень` / `🗓 Парний тиждень` — перегляд усього розкладу за відповідним типом тижня.
   - `📆 Обрати день` — інлайн-кнопки (Пн, Вт, Ср, Чт, Пт).
   - `ℹ️ Поточний тиждень` — відображає номер поточного навчального тижня та його тип.
   - `🔄 Оновити розклад` — миттєва примусова перевірка наявності нового файлу на Google Drive.
4. **Посилання на заняття:**
   - Усі посилання на **Zoom**, **Google Meet**, **Google Classroom**, а також ідентифікатори конференцій та коди доступу виводяться у зручному клікабельному вигляді.

## ⚙️ Встановлення та налаштування

### 1. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 2. Створення файлу `.env`
Скопіюйте `.env.example` у `.env`:
```bash
cp .env.example .env
```
Відкрийте `.env` і вставте токен вашого бота від `@BotFather`:
```ini
BOT_TOKEN=ваш_токен_від_BotFather
GROUP_NAME=РЗ-263
GDRIVE_FOLDER_ID=1Jlt45-PyFNJjfbNw1UVHWQ9GxzT5xizo
SEMESTER_START=2026-08-31
CHECK_INTERVAL_SECONDS=1800
```

---

## 🚀 Запуск бота

### Звичайний запуск:
```bash
python main.py
```

### Тестовий парсинг без запуску бота в Telegram:
```bash
python main.py --test
```
